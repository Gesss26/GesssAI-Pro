# ⚽ GesssAI-Pro - Football Trader

App di trading scommesse con analisi statistiche automatiche.

## 🚀 Caratteristiche

- 📊 Analisi statistica di **18 campionati** di calcio
- 🤖 Giocate calcolate automaticamente con percentuali
- 💣 Identificazione delle "Bombe" (giocate con ≥ 90% di probabilità)
- 🌤️ Integrazione meteo
- 📱 Design responsive

## 🌐 App Live

L'app è disponibile all'indirizzo:
👉 **https://[tuo-username].github.io/gesssai-app/**

I dati vengono **aggiornati automaticamente ogni giorno** alle 3:00 AM UTC.

## 📊 Dati Aggiornati

I dati vengono scaricati da **FBref** e includono:

- Allsvenskan (Svezia)
- Austrian Bundesliga (Austria)
- Chinese Super League (Cina)
- Danish Superliga (Danimarca)
- Eliteserien (Norvegia)
- Eredivisie (Olanda)
- La Liga (Spagna)
- League of Ireland Premier Division (Irlanda)
- J1 League (Giappone)
- K League 1 (Corea del Sud)
- Russian Premier League (Russia)
- Swiss Super League (Svizzera)
- Veikkausliiga (Finlandia)
